Static marketing site for Advera Creative (plain HTML pages, `render.yaml` deploy). No build step.

## Token guard
- Be concise: answer first, no preamble, no recap of what you just did.
- Route mechanical work (renames, formatting, summarizing, scraping, bulk find/replace) to a sub-agent with `model: haiku`; keep the main model for judgment and design.
- Never suggest `/compact` as a cost-saving measure (it rewrites the cache). Suggest `/clear` between unrelated jobs instead.
- Don't switch model or effort mid-session.
- Read only the file sections you need; don't re-read files already in context.
