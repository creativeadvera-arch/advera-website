Every change has a reason.

  1. Exact duplicates: removed repeated WO-101 and WO-104 only after confirming matching source records. No fuzzy merges or guessed identities.
  2. Date formats: normalised to ISO YYYY-MM-DD, using a stated Australian day-month-year rule for the ambiguous input 03-11-2026. On client work, the owner approves any ambiguous interpretation.
  3. Labels and whitespace: standardised status variations and trimmed one extra-spaced client field.
  4. Missing value: left WO-105's status empty and added a review flag instead of inventing a value.

All work orders and company names here are fictional; the sample contains no real customer information. Actual projects require agreed duplicate keys, file dimensions, permissions, delivery criteria and payment terms before production. No hidden customer results or performance guarantees.
